# hella-claim-scope

## 用途

执行 W3：审核代理人稿的形式、支撑、必要特征和范围松紧。本工作流不直接改稿。

## 何时用

用户要求审权利要求、审代理人稿、检查保护范围或对比底稿与代理人稿。

## 输入

权利要求书、说明书、原交底；可选 W1 案件和 W6 申请底稿。

## 步骤

1. 解析权利要求和说明书，拆特征与段落。
2. 用 `uv run shared/claims/audit_claims.py` 检查编号、引用、过渡语、宣传措辞和引用基础。
3. 运行支撑检查，逐特征映射说明书段号。
4. 做删除测试，区分必要与优选特征。
5. 审核独权范围和从属四层布局。
6. 与交底、可选底稿比较；新增特征单独补检。
7. 输出审核意见；需要修改时转 W7。

## 护栏

结构检查通过不等于可以提交。不得把没有说明书支撑的特征写入修改建议。W3 只审不改。

## 产出物

权利要求审核意见 docx、`work/findings.json`、`work/feature_support.json`。
